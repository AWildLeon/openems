= FoxESS H3 Meter

Implements the FoxESS H3 integrated meter using Modbus communication.

This meter implementation reads grid measurements, energy counters, and load data from the FoxESS H3 inverter. It provides standard ElectricityMeter functionality for OpenEMS.

== Features

* Three-phase voltage, current, and power measurements
* Grid frequency measurement  
* Smart meter import/export energy counters
* Load energy counters
* Configurable meter type (Grid, Production, Consumption)
* Power value inversion support

== Modbus Registers

The following Modbus registers are read from the FoxESS H3:

* 31006-31015: Grid measurements (voltage, current, power, frequency)
* 32013-32014: Smart meter import energy counters
* 32016-32017: Smart meter export energy counters  
* 32022-32023: Load energy counters

== Configuration

* **Component-ID**: Unique ID of this Component
* **Alias**: Human-readable name of this Component
* **Meter-Type**: Grid (default), Production, or Consumption
* **Modbus-ID**: ID of Modbus bridge
* **Modbus Unit-ID**: The Unit-ID of the Modbus device (default: 1)
* **Invert Power**: Inverts all Power values (multiply by -1)

== Usage

This meter can be used alongside the FoxESS H3 BatteryInverter or as a standalone meter component for monitoring grid connection, production, or consumption depending on the configured meter type.
